Single-file FastAPI `APIRouter` (`media.py`) that contains only HTTP input validation and dispatch; all business logic (authorization, storage-backend/provider resolution, byte serving, and access-descriptor construction) is delegated to `app.services.media_access` functions (`resolve_authorized_media`, `_resolve_servable_backend_and_ref`, `_resolve_variant_serve_ref`, `serve_media_bytes`, `build_access_descriptor`). Four route pairs are defined — top-level `/media` and `/media/access`, plus nested `/nested-media/{item_path}` and `/nested-media/{item_path}/access` — each sharing the same authorization flow via `resolve_authorized_media` with an optional `item_path` parameter. A custom `BaseHTTPMiddleware` (`MediaAccessNoStoreMiddleware`) enforces `Cache-Control: no-store` on every response (success and error paths) for both `/media/access` and `/nested-media/.../access` routes using a compiled regex path matcher, because exception-generated responses bypass per-route header mutations. Entity context resolution (`mode`/`staff_id`/`contact_id`/`conversation_type`) is reused from `app.services.timeline_service` helpers. Dependency injection uses `get_db` for SQLAlchemy sessions and `get_current_user` for authentication, returning `(AdminUser, tenant_id)` tuples where `tenant_id` is derived solely from the authenticated session and never accepted from request parameters.
