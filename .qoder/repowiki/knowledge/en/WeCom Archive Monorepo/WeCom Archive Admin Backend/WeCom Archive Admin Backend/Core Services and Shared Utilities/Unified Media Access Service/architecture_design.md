Single-file service module extracted from `app.routers.conversations` as part of RND-221. It exposes three public entry points used by the media routes: `resolve_authorized_media` (unified conversation membership + message ownership + msgtype gate + MediaFile lookup for both top-level and nested paths), `serve_media_bytes` (provider-agnostic byte proxy returning FastAPI `Response`/`FileResponse` with private cache headers), and `build_access_descriptor` (produces either a proxy URL or a Qiniu signed URL depending on the row's `storage_backend`). Internal helpers `_validate_nested_media_path`, `_find_nested_media_ref`, `_resolve_variant_serve_ref`, and `_resolve_servable_backend_and_ref` encapsulate nested-path grammar validation, media_refs lookup against a message's own `structured_content`, thumbnail variant selection, and effective backend/ref resolution. Dependency direction is one-way: this module depends on `app.media_storage` (provider abstraction, content-type detection, signed-URL deadline), `app.media_download` (nested media iteration), and `app.conversation_membership` (conversation membership checks); it never imports back into routers or schemas beyond the `MediaAuthResult` dataclass return shape.
