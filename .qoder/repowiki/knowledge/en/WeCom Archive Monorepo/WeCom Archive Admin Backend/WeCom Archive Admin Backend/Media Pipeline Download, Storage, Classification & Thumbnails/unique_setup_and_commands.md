Behavior is controlled entirely by environment variables: `MEDIA_STORAGE_PROVIDER` (or legacy `STORAGE_BACKEND`) selects `local` vs `qiniu_kodo`; `STORAGE_LOCAL_PATH` sets the local root; `QINIU_ACCESS_KEY`/`QINIU_SECRET_KEY`/`QINIU_BUCKET`/`QINIU_DOMAIN`/`QINIU_REGION`/`QINIU_TIMEOUT_SECONDS` configure Qiniu; `MEDIA_SIGNED_URL_TTL_SECONDS` and `MEDIA_SIGNED_URL_WINDOW_SECONDS` control signed-URL expiry windows; `MEDIA_THUMBNAIL_ENABLED`/`MEDIA_THUMBNAIL_MAX_EDGE`/`MEDIA_THUMBNAIL_JPEG_QUALITY` tune thumbnail generation. The CLI entry point is `scripts/download_wecom_media_once.py` (and separate backfill scripts) which drive the pipelines.
