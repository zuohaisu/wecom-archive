First-time server setup requires installing git/python3/pip/curl, creating the `wecomarchive` user, cloning the repo into `/srv/apps/wecom-archive-365/current`, bootstrapping a `.venv`, placing `backend/.env` with `DATABASE_URL`, installing the systemd unit files, and granting passwordless sudo for `systemctl restart wecom-archive-365.service` via `/etc/sudoers.d/wecomarchive`. The deploy script is invoked as `sudo -u wecomarchive bash scripts/deploy_server.sh` (or from CI with `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`, `DEPLOY_PORT` secrets). Tests are run via BATS with `bats scripts/tests/deploy_server.bats`.
