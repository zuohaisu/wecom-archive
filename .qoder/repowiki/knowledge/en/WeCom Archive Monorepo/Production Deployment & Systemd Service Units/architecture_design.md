Two complementary artifacts under this scope:
- `scripts/deploy_server.sh` is a single self-contained Bash deployment pipeline that pulls code, installs Python deps, compiles, runs Alembic migrations, verifies DB revision against repo head, restarts the systemd service, and gates success on both an internal `/health/ready` endpoint and a public `/health` probe. It enforces a clean working tree, uses `flock` for concurrency protection, pins deployments to an `EXPECTED_SHA` when supplied by CI, persists a `last_known_good_sha` outside the git tree for rollback targeting, and performs an automatic rollback (code checkout + dep reinstall + restart + health gate) without ever running `alembic downgrade`.
- `deploy/systemd/*.service` and `*.timer` files define the runtime services: `wecom-archive-worker` (oneshot, triggered every 5 min via its timer), `wecom-thumbnail-backfill`, `wecom-archive-media-download`, and a templated `qiniu-ssl-renew@.service` driven by per-domain env files under `/etc/qiniu-ssl-renew/<domain>.env`. All units run as the `wecomarchive` user with hardened security profiles (`ProtectSystem=strict`, `NoNewPrivileges=yes`, restricted address families).
- Tests live under `scripts/tests/` using BATS; `common.bash` builds a fully isolated fixture tree and replaces every external command (`git`, `python`, `systemctl`, `curl`, `flock`, `mv`) with mock scripts under `test_helper/mock_*.sh`, so the deploy script is exercised end-to-end against no real system state.
