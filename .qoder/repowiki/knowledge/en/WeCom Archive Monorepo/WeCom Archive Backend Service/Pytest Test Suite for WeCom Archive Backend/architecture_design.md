Flat collection of pytest modules under `backend/tests/`, each file targeting a specific feature or RND ticket. Tests are organized by concern rather than layer: auth (`test_auth.py`), media/Qiniu (`test_qiniu_*.py`, `test_media_*.py`), message type registry and JS rendering (`test_message_type_registry.py`, `_rnd216_web_shims.py`), tenant isolation (`test_tenant_*.py`), migrations/backfills (`test_backfill_*.py`, `test_revoke_*_migration.py`), and admin console HTML/JS (`test_admin_*.py`). Shared test helpers live in `_rnd216_web_shims.py`, which reconstructs the review console's bundled JS from externalized static files so Node-based assertions work without a running server. FastAPI `TestClient` is used throughout with `app.dependency_overrides` to swap out `get_db` and `get_current_user` with `MagicMock` fixtures, keeping most tests DB- and network-free. Integration tests that need a real database gate themselves on the `DATABASE_URL` environment variable via `@pytest.mark.skipif`. Some tests execute embedded JavaScript through `subprocess` against a local `node` binary, gated by `shutil.which('node')`.
