Requires the WeCom C SDK shared library file path passed to `load_sdk()` and exported symbols for each feature group must be present — `configure_sdk_media_data` raises `AttributeError` if media-download symbols are missing, allowing graceful fallback. Environment variables `WECOM_CALLBACK_TOKEN`, `WECOM_CALLBACK_ENCODING_AES_KEY`, and `WECOM_CORP_ID` must be set before the router starts.
