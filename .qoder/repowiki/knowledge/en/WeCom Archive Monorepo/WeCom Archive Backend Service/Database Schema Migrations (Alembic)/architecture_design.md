Standard Alembic layout under `backend/alembic/` with three core pieces: `env.py` bootstraps the migration environment by injecting `backend/` into `sys.path`, importing `app.db.base.Base` and `app.db.models` to register ORM models, and resolving the database URL from `DATABASE_URL` or `DB_HOST`/`DB_PORT`/`DB_NAME`/`DB_USER`/`DB_PASSWORD` environment variables. `script.py.mako` is a custom Mako template that generates new migration files with typed `upgrade()`/`downgrade()` signatures. The `versions/` directory holds 12 sequential migrations (`0001_initial_schema.py` through `0012_media_thumbnails.py`) forming a linear chain via `revision`/`down_revision` strings. Each migration is self-contained and uses SQLAlchemy's `op.*` DDL operations rather than raw SQL (except for GIN full-text indexes). Migration 0009 introduces the `message_revocations` association table following the established child-table pattern seen in `archive_message_recipients` and `media_files`.
