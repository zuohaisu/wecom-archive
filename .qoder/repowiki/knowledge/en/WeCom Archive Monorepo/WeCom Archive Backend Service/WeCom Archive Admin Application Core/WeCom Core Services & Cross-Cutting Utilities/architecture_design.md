This scope groups utilities that sit between SQLAlchemy models and FastAPI routers, with a strict downward dependency direction. `message_type_registry.py` is the single source of truth: it defines frozen `MessageTypeDefinition` dataclasses plus enums (`MessageCategory`, `MessageSupportStatus`, `MediaCapability`, `ParserStrategy`, `RendererStrategy`) and exposes a read-only `MESSAGE_TYPE_REGISTRY` with `resolve()`, `describe_message_type()`, `build_support_matrix()`, and `build_frontend_registry_entries()` so both Python code and the embedded frontend share one catalog. `structured_message_parser.py` implements per-msgtype field extractors referenced by the registry's `ParserStrategy` entries, each returning `(fields, warnings)` without raising. `services/listing_service.py` is a pure service layer exposing `list_monitored_accounts`, `list_contacts`, `list_conversations` using compact SQLAlchemy projections via `_compact_entity_messages`. `display_names.py`, `html_helpers.py`, and `i18n_assets.py` are stateless helpers consumed by admin UI rendering; `i18n_assets.py` reads `assets/i18n.js` at import time to expose `I18N_JS_SOURCE` / `I18N_SCRIPT_TAG`. `revoke_reconciliation.py` provides idempotent linking of `msgtype="revoke"` events via `MessageRevocation` with SAVEPOINTs and conditional SQL UPDATEs. No circular imports exist within this scope.
