The `backend/` package is organized into four cooperating layers around a shared SQLAlchemy model layer in `app/db/models.py`. The runtime core (`app/`) bootstraps the FastAPI application in `main.py`, registers HTTP routers from `routers/` (auth, conversations, messages, search, web UI, WeCom events), and composes business logic through `services/` plus domain modules like `media_storage.py`, `wecom_contacts.py`, and `structured_message_parser.py`. `alembic/` owns versioned DDL evolution against PostgreSQL, driven by `alembic.ini` and applied independently of the app process. `scripts/` provides idempotent one-shot utilities that import directly from `app.db.models` to backfill or migrate data without going through HTTP. `tests/` uses pytest fixtures that instantiate the same FastAPI app and database session used at runtime, ensuring end-to-end coverage across routers, media backends, and migration correctness. All layers share the SQLAlchemy model definitions as the single source of truth for persistence contracts.
