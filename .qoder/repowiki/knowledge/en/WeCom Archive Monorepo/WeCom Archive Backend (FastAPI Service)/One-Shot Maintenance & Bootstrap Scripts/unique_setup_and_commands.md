Scripts are run from the `backend/` directory so the relative `sys.path.insert(0, ...)` resolves the `app` package without installation. Each requires `DATABASE_URL` plus WeCom-specific env vars (`WECOM_CORP_ID`, `WECOM_ARCHIVE_SECRET`, `WECOM_SDK_LIB_PATH`, etc.). Typical invocation: `python scripts/<script>.py`. Some accept CLI flags (e.g. `--tenant-id`, `--query-sender`, `--query-text`, `--batch N`).
