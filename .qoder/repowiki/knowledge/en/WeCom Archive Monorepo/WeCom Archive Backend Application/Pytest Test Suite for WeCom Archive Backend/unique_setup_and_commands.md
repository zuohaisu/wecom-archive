Run from `backend/`: `pytest tests/test_<name>.py -v`. Database-backed tests require `DATABASE_URL` set to a valid PostgreSQL DSN; they are skipped otherwise. Node.js must be available on PATH for any test that executes embedded JS (e.g. `test_message_type_registry.py`); those tests skip when `node` is not found. Many integration/migration tests set `DATABASE_URL` via `monkeypatch.setenv` before invoking CLI commands like `alembic upgrade head` or custom backfill scripts.
