Single-file Pydantic schema module under `backend/app/schemas/` that exports two BaseModel subclasses — `MediaAccessOut` (unified media access descriptor used by the top-level media endpoints) and `NestedMediaAccessOut` (a deliberately separate model for nested mixed/chatrecord media, omitting the internal `media_id` primary key to enforce a stricter public contract). The file is a direct migration artifact from `app.routers.conversations`, kept field-for-field identical per RND-221. Dependency direction is one-way: routers import these schemas as response models; no business logic lives here.
