The repository is a monorepo with four distinct child modules sharing a common Python 3.11+ runtime and PostgreSQL 14+ datastore. The `backend_app` exposes the WeCom archive REST API and admin console; `deployment_infra` provides Bash-driven push-to-deploy with automatic rollback plus systemd service/timer units for the worker, thumbnail backfill, and SSL renewal; `ssl_renew_tool` is an independent acme.sh + Qiniu CDN automation packaged under `ssl-renew/`; `docs_and_design` holds architecture docs, ADRs, runbooks, and the static company homepage. Cross-child wiring is done at the repo root via `Makefile`, which orchestrates lint/typecheck/build/test (`make verify`) over both the backend and the ssl-renew scripts using a single `.venv/` at the workspace root, and via shared environment conventions defined in `.env.example`. All children depend on the same PostgreSQL schema managed by Alembic migrations inside `backend/alembic/`, and secrets flow through `.env` files that are gitignored globally.
