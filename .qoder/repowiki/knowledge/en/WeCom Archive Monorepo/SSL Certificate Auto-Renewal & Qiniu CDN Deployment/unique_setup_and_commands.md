Run `make ssl-test` for the full 137-test suite (108 bats + 29 pytest, all mocked), `make ssl-lint` for shellcheck/shfmt/python linting, `make ssl-dry-run` for smoke testing with example.com, and `make ssl-verify-systemd` for unit file validation. On macOS, build the Docker image with `docker build -t ssl-renew-verify -f ssl-renew/Dockerfile .` and run acceptance checks inside it. Per-domain setup: copy `examples/domain.env.example` to `/etc/qiniu-ssl-renew/<domain>.env`, set `DOMAIN`, `QINIU_ACCESS_KEY`, `QINIU_SECRET_KEY`, `ALERT_WEBHOOK_URL`, then `chmod 600` the env file and enable with `systemctl enable --now qiniu-ssl-renew@<domain>.timer`.
