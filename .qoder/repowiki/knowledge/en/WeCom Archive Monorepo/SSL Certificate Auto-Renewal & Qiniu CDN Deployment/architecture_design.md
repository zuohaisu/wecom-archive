Single-purpose Bash automation suite centered on `renew.sh` as the main orchestrator, which sources two library modules from `lib/`: `common.sh` (shared logging, secret redaction via `filter_secrets`, domain validation, config loading from systemd `EnvironmentFile`, timeout wrapper, exit codes) and `qiniu.sh` (thin shell wrapper around `qiniu_helper.py`). The Python helper `qiniu_helper.py` is a strict subprocess boundary — all Qiniu API signing is delegated to the official `qiniu` SDK (`Auth`, `DomainManager`), never reimplemented in shell. Three independent entry points exist: `renew.sh` (full pipeline), `verify_https.sh` (standalone TLS/HTTPS checker), and `notify.sh` (generic JSON webhook notifier). Configuration is per-domain via `/etc/qiniu-ssl-renew/<domain>.env` files sourced through `CONFIG_FILE`. State lives under `$HOME/.acme.sh/<domain>/` (`.deployed_fp`, `.tls_verified`, `.tls_mismatch_days`, `.renew.lock`) with `flock`-based idempotency guard. `install.sh` is an idempotent preflight/installer that refuses non-Linux hosts for systemd steps. A Dockerfile provides a Debian-based verification image for macOS developers. Tests use `bats-core` for shell scripts and `pytest` for Python parity tests against the official SDK.
