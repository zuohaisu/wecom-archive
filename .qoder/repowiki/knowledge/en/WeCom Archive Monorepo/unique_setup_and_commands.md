`make verify` chains `lint-diff → typecheck → build → test` for developer acceptance on the backend; `make ssl-lint` runs shellcheck/shfmt/py_compile over the SSL scripts; `make ssl-test` executes the bats suite plus pytest against the qiniu_helper module; `make ssl-dry-run` exercises renew.sh against example.com with DRY_RUN=1; `make ssl-verify-systemd` validates systemd units via `systemd-analyze verify` (native or Docker fallback). Local backend bring-up follows the README Quick Start: create `.venv`, install requirements, copy `.env.example`, run `alembic upgrade head` and `bootstrap_default_tenant.py`, then `uvicorn app.main:app --reload`.
