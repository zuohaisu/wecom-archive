Single-root virtualenv at `.venv/` covers all Python dependencies (backend + ssl-renew dev deps). Developer acceptance pipeline: `make verify` runs `lint-diff → typecheck → build → test` in sequence. Separate targets exist for each subsystem: `make lint` / `make test` for backend, `make ssl-lint` / `make ssl-test` / `make ssl-dry-run` / `make ssl-verify-systemd` for the SSL tool. Local backend bring-up follows the README Quick Start steps (create venv, install requirements, copy `.env.example`, bootstrap tenant, `alembic upgrade head`, then `uvicorn app.main:app`).
