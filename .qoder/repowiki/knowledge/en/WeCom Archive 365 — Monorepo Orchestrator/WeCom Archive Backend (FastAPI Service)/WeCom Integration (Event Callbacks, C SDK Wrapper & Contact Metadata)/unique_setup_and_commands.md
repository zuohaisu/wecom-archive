The C SDK shared library must be present at a configurable path and loaded via `load_sdk(lib_path)` before any `configure_sdk_*` calls; media-download symbols (`GetData`, `GetOutIndexBuf`) may be absent in some deployments and must be handled gracefully via `AttributeError` in `configure_sdk_media_data`. Event callback encryption requires `WECOM_CALLBACK_TOKEN`, `WECOM_CALLBACK_ENCODING_AES_KEY` (43-char base64 key), and optionally `WECOM_CORP_ID` to be set in the process environment.
