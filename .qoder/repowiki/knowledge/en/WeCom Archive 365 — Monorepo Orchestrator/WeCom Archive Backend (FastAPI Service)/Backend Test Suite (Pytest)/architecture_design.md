Flat collection of pytest modules under `backend/tests/`, each file targeting a specific feature or migration. Shared test infrastructure lives in `_rnd216_web_shims.py`, which reassembles the review console, search page, and diagnostics HTML/JS bundles that were extracted from inline Python strings into external templates and static files during RND-216/RND-217. Tests use FastAPI's `TestClient` against `app.main.app`, override dependencies via `app.dependency_overrides` (e.g. `get_db` mock), and employ `pytest.mark.parametrize`, `monkeypatch`, and `MagicMock` extensively. Node-dependent tests are gated with `pytestmark = pytest.mark.skipif(NODE is None, ...)` so they run without a Node runtime. Database-backed tests are skipped unless `DATABASE_URL` is set, allowing pure unit tests to pass in CI without a live DB.
