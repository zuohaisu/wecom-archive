Provider selection via `MEDIA_STORAGE_PROVIDER` env var (defaults to `local`, supports `qiniu_kodo`). Qiniu requires `QINIU_ACCESS_KEY`, `QINIU_SECRET_KEY`, `QINIU_BUCKET`, `QINIU_DOMAIN` (must be HTTPS), optional `QINIU_REGION` and `QINIU_TIMEOUT_SECONDS`. Thumbnail generation controlled by `MEDIA_THUMBNAIL_ENABLED`, `MEDIA_THUMBNAIL_MAX_EDGE`, `MEDIA_THUMBNAIL_JPEG_QUALITY`. Signed URL TTL/window via `MEDIA_SIGNED_URL_TTL_SECONDS` and `MEDIA_SIGNED_URL_WINDOW_SECONDS` (bounded [60,3600]). Local media root via `STORAGE_LOCAL_PATH`.
