The module is a thin Flask-facing layer that serves static HTML/CSS/JS without a template engine. `__init__.py` defines a single-pass `render_template()` that substitutes `__TOKEN__` placeholders (e.g. `__I18N_SCRIPT__`, `__MTR_ENTRIES_JSON__`, `__STATIC_VERSION__`) into `.html` files under `templates/`, and computes an MD5-based cache-busting version over all files in `static/`. The frontend is organized as a set of vanilla JS modules loaded in dependency order: `console-state.js` (global state), `api-client.js` (HTTP calls), `conversation-list.js`, `timeline.js`, `message-renderers.js`, `media-viewer.js`, `refresh.js`, and `console-entry.js` (bootstrap). Each page template (`review_console.html`, `messages.html`, `message_detail.html`, `diagnostics.html`, `search.html`) embeds the shared CSS (`base.css`, `diagnostics.css`) and wires the JS via `<script src=...?v=__STATIC_VERSION__>`. There is no build step — assets are served directly from disk and rehashed on process import.
