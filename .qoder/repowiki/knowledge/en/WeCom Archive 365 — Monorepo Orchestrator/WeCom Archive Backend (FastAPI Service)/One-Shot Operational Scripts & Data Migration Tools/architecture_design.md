Each file is an independent, self-contained CLI entry point with a `main()` function invoked via `if __name__ == "__main__"`. Scripts are not imported by the application runtime — they import from `app.db.models`, `app.sdk.wecom_sdk`, and `app.media_storage` only at runtime. Dependency direction is strictly outward: scripts depend on the application's SQLAlchemy models, SDK wrappers, and storage providers, but nothing in `app/` depends back on `scripts/`. Scripts fall into four categories: (1) bootstrap/migration tools (`bootstrap_default_tenant.py`, `backfill_*.py`, `migrate_local_media_to_qiniu.py`) that mutate schema/data; (2) sync workers (`sync_wecom_archive_once.py`, `run_archive_worker_once.py`, `download_wecom_media_once.py`, `decrypt_wecom_messages_once.py`) that call the WeCom Finance C SDK via `app.sdk.wecom_sdk`; (3) verification/integrity checks (`verify_alembic_head.py`, `check_message_revocations_integrity.py`); (4) development helpers (`mock_ingest.py`, `smoke_wecom_*`). All scripts add `backend/` to `sys.path` so they can be run directly from the `backend/` directory without installation.
