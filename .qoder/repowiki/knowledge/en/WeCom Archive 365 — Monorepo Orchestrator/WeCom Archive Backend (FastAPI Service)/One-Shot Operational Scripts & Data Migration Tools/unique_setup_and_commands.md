Scripts are executed directly from the `backend/` directory as `python scripts/<script>.py`. Each requires `DATABASE_URL` and specific WeCom env vars (`WECOM_CORP_ID`, `WECOM_AGENT_ID`, `WECOM_OAUTH_SECRET`, `WECOM_ARCHIVE_SECRET`, `WECOM_SDK_LIB_PATH`). The Alembic head verification script is designed to be called from `scripts/deploy_server.sh` as a deployment gate. Media migration uses a non-blocking `fcntl.flock` file lock (default `/srv/apps/wecom-archive-365/shared/run/wecom-media-migration.lock`) to prevent concurrent runs.
