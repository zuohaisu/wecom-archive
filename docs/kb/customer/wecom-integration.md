# 企业微信接入与常见错误

本文档说明企业微信与康冠时代企业微信会话存档之间的接入方式、开通步骤，以及授权失败时的常见排查方法。云托管版可使用第三方应用授权；自托管版由部署者自行配置企业微信应用和受保护的运行凭据。

## 接入方式概述

企业微信侧需要具备两件相互独立的事情，接入前请分清楚：

1. **企业微信官方"会话存档"能力**：这是企业微信自己提供的合规存档功能，需要企业按照企业微信的规则在**企业微信管理后台**中自行开通，并承担企业微信官方收取的相关费用。这部分费用**不包含**在康冠时代的年度套餐价格中，两者分开结算。
2. **康冠时代产品与企业微信之间的授权连接**：即企业微信将会话存档数据、身份信息等，通过官方接口授权给康冠时代系统读取。这一步是本产品需要客户完成的接入操作。

新客户通常通过"企业微信授权安装"的自助开通流程接入：管理员在康冠时代登录页发起授权，跳转到企业微信完成同意操作，返回后确认企业名称，系统随即为该企业创建一个独立的组织（租户），并自动开始一次限时免费试用（详见「常见问题」）。

## 授权流程步骤

1. 管理员打开康冠时代登录页，选择"企业微信授权安装"（或类似入口）。
2. 系统跳转到企业微信的授权确认页面，管理员使用企业微信账号登录并同意授权。
3. 企业微信将授权结果回调给康冠时代系统。系统会读取企业微信返回的**官方企业名称**，并在一个确认页面上展示给管理员核对（该名称来自企业微信，无法在此页面修改）。
4. 管理员点击"确认创建"后，系统正式创建该企业的独立组织空间，并将发起授权的账号设为该组织的所有者（Owner）。
5. 组织创建完成后进入"配置准备"状态：此时归档任务尚未启动，管理员需要按照系统内的指引完成必要配置（例如确保企业微信官方会话存档功能已开通、相关应用权限已授予等）。系统会进行自动检查；检查通过后开始 15 天免费试用，无需先付款即可使用完整功能。

对于既有的自建应用配置方式（管理员在系统"设置"页手动填写企业微信的 CorpID、AgentID、应用 Secret 等参数），也可以完成同等效果的接入；具体以系统内"设置 → 企业微信"分组下实际展示的表单为准，相关字段均为必填项。

无论采用哪种方式，企业微信侧的具体操作入口和界面文案请以**企业微信管理后台自身的界面**为准（例如"应用管理"中开通会话存档、配置可信域名/回调地址等），本产品不代替企业微信官方文档描述这些界面细节。

## 常见错误与排查

授权或登录过程中出现问题时，系统通常会把你带回登录页并附带一个状态标识，代表不同的失败原因。下表列出目前已知的几类情况，供排查参考（这些是本系统内部的处理状态，并非企业微信官方错误码）：

| 状态含义 | 可能原因 | 建议处理 |
|---|---|---|
| 系统配置异常 | 康冠时代系统自身的企业微信对接配置暂时不可用 | 请稍后重试；如持续出现，请联系客服，这通常不是客户侧操作问题 |
| 授权确认失败 | 企业微信返回的授权信息校验未通过，或授权过程中途中断/超时 | 请重新发起一次授权流程；确认在企业微信侧点击了"同意"而不是"拒绝"或直接关闭页面 |
| 该企业已存在 | 这家企业此前已经通过本系统完成过组织创建 | 不要重复创建，改为使用已有账号登录；如忘记登录方式，请联系客服协助找回 |
| 账号未激活/已停用 | 用于登录的企业微信账号在企业微信内被标记为未激活或已离职 | 请使用企业内当前活跃的账号登录，或联系企业微信管理员检查账号状态 |
| 访问审批中 | 账号存在但尚未获得系统内的访问权限 | 等待企业管理员在系统内为该账号完成授权，或联系管理员处理 |
| 授权状态已过期 | 授权跳转过程耗时过长，一次性状态令牌已失效 | 从登录页重新发起授权，不要使用浏览器"前进/后退"回到过期的中间页面 |
| 未找到对应企业 | 授权流程未走完组织确认步骤就中断了 | 从登录页重新开始完整的授权流程 |

## 通用排查顺序

如果遇到的提示不在上表中，或者提示信息与实际情况看起来不匹配，建议按以下顺序排查：

1. **确认企业微信官方会话存档功能状态**：在企业微信管理后台检查会话存档相关应用是否处于正常启用状态、是否有企业微信官方发出的到期或异常提醒。
2. **确认操作账号权限**：确保当前登录企业微信的账号在企业内处于活跃状态,并具备完成该操作所需的权限（例如企业主体管理员权限）。
3. **重新完整走一遍授权流程**：不要从浏览器历史记录中的中间页面继续操作，从登录页重新发起，避免使用已过期的一次性状态。
4. **检查网络与时间**：确保发起授权的设备网络正常，系统时间没有明显偏差（企业微信的签名校验对时间戳敏感）。
5. **仍无法解决时联系客服**：请提供大致的操作步骤、出现问题的时间点，以及登录页地址栏中的状态标识（如果有），方便快速定位；无需提供任何密码、密钥等敏感信息。

## 联系方式

如接入过程中遇到无法自行解决的问题，请联系客服（首页/定价页提供的联系邮箱），并说明团队规模与目前的企业微信会话存档配置进展，以便我们更快协助排查。
