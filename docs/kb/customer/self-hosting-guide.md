# 自托管安装与升级指南

## 当前提供形态：云托管服务

康冠时代企业微信会话存档目前面向客户提供的是**云托管（SaaS）服务**：企业完成企业微信授权和必要配置后，即可直接使用，不需要自己准备服务器、数据库或运维人员。产品的年度基础套餐（99 元/年，含 5 GiB 存储、不限座席）就是基于这个云托管服务定价的。

我们**当前没有面向客户发布的"自助安装向导"或一键部署包**。如果你在寻找可以自己在企业服务器上部署运行的版本，请继续阅读下面的说明。

## 内部部署路径说明

产品内部有一份面向运维/工程团队的部署文档（`docs/DEPLOYMENT.md`），描述的是我们云托管服务自身在服务器上的部署方式，包括：

- 运行环境要求（Python 3.11、PostgreSQL、Alibaba Cloud ECS 等）
- 应用初始化步骤（安装依赖、执行数据库迁移、初始化默认租户）
- 一组后台定时任务，用于会话同步、媒体下载、外部联系人刷新、留存锁定、导出任务、账单通知等工作
- 代码发布与数据库迁移的自动化流程（含健康检查、迁移校验、失败自动回滚等安全机制）

这份文档是**内部运维说明**，其中包含生产环境主机、反向代理、部署脚本回滚机制等运维细节，不是为客户自助安装设计的操作手册，也不保证在客户自有环境中开箱即用。

## 如需自托管部署

如果你的团队确实需要在自己的服务器/私有环境中独立部署本产品（而不是使用我们的云托管服务），请联系我们说明具体需求（团队规模、合规要求、目标环境等）。我们会评估并与你沟通具体的交付方式；这不是当前标准产品能力的一部分，需要单独安排。

## 云托管版本的运维方式（客户视角）

作为使用云托管服务的客户，你不需要关心具体的部署细节，但可以了解以下几点，便于理解系统的可靠性：

- 后台会话同步和媒体下载由自动化定时任务持续运行，不需要客户手动维护；如遇同步异常，管理后台会显示状态，也支持手动触发一次同步（详见「故障排查」）。
- 系统更新（新功能上线、缺陷修复）通过内部自动化发布流程完成，发布过程包含数据库结构校验和健康检查，异常时会自动回滚，以降低发布对正在使用的客户造成影响。
- 你的企业数据在服务端按租户严格隔离，具体机制参见「常见问题」中关于多租户隔离的说明。
