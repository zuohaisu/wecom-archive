# 故障排查

本文档面向客户，说明遇到同步、媒体下载、登录/权限、存储配额等问题时，可以自己动手排查的步骤。如果按下面的步骤仍无法解决，请联系客服并提供你在系统内看到的具体状态提示。

## 同步失败 / 长时间没有新消息

系统会持续从企业微信官方会话存档接口拉取消息；正常情况下不需要人工干预。如果怀疑同步出了问题：

1. **查看系统内的同步状态**：在管理后台的总览或"同步状态"入口，检查最近一次同步时间和当前状态（空闲/同步中/出错）。如果状态显示"出错"，通常说明最近一次同步任务失败，需要进一步排查配置。
2. **尝试手动触发一次同步**：系统提供"立即同步"操作。点击后系统会在后台执行一次同步；短时间内重复点击会被提示"正在同步中"或"请稍后再试"，这是正常的限流保护，等待提示的冷却时间后再试即可。
3. **检查企业微信官方会话存档应用状态**：在企业微信管理后台确认会话存档相关应用是否正常启用，没有被停用、到期或收到企业微信官方的异常通知。
4. **检查企业微信侧接入配置是否有变动**：例如企业微信应用的密钥被重置、可信域名/回调地址被修改等，都可能导致系统与企业微信之间的连接失效，需要参考「企业微信接入与常见错误」重新确认接入配置。
5. **确认距离上次操作的时间**：如果是刚完成企业微信授权或修改了配置，同步可能需要一小段时间才能生效，建议先等待几分钟再检查状态。

如果以上步骤都确认正常，但同步状态仍持续显示错误，请联系客服并说明具体的错误提示文字和大致发生时间。

## 媒体（图片/语音/视频/文件）下载失败或一直"未完成"

- 媒体下载与文本消息同步是两个独立的过程，文本消息可以正常显示，图片等媒体仍在下载中属于正常现象，通常会在后续的处理周期内自动补齐。
- 如果某条媒体长时间停留在"未完成"或明显不再变化，先检查"套餐与容量"页面：**存储配额已满是媒体无法完成下载的常见原因之一**（见下文"存储配额告警"）。配额恢复后，系统会在下一轻处理周期内自动重试，不需要手动干预。
- 如果存储配额充足但媒体依然长期无法完成，可能是该条消息本身在企业微信侧已不可获取（例如超出企业微信官方媒体保留时长），这种情况下系统会将其标记为失败并保留失败记录，不会无限重试。属于正常的边界情况，无需反复触发同步。
- 排查前建议先确认：该消息在企业微信官方会话存档范围内本身是否可以正常查看/回放,以排除企业微信侧的数据本身就不可用的情况。

## 登录 / 权限问题

- **企业微信授权登录失败**：如果登录后被带回登录页并看到状态提示（例如授权失败、账号未激活、访问审批中等），请参考「企业微信接入与常见错误」中的对照表逐项排查，多数情况与企业微信账号状态或授权流程中断有关。
- **看不到某些菜单或操作按钮**：系统按角色（Owner/管理员/合规/法务/只读审计等）区分功能可见范围,属于正常权限设计。如果你认为自己的角色应该有更高权限，请联系企业内的 Owner 或管理员确认/调整你的账号角色。
- **忘记密码（密码登录模式）**：请联系企业内的管理员通过系统内的账号管理流程协助重置，不要在工单或聊天记录中直接发送密码本身。
- **会话过期需要重新登录**：登录会话有效期为 8 小时，超时后重新走一次登录流程即可，属于正常安全设计。

## 存储配额告警

在"套餐与容量"页面可以查看当前套餐配额、已用容量、剩余容量及状态：

- 容量处于正常范围时不需要处理。
- 当使用率接近上限（提示"接近上限"一类的告警状态）时，建议提前规划：清理不必要的历史媒体（如有相关功能）、或考虑升级容量套餐,避免影响到新的媒体归档。
- 当容量**已满**时，系统会明确阻止新的媒体写入，**但不会删除任何已有的消息或媒体记录**——文本消息仍会正常继续归档，只是新的图片/语音/视频/文件类媒体会暂时排队等待，直到容量恢复。这是刻意的保护设计，不是数据丢失。
- 处理方式：联系客服升级套餐容量，或确认是否有可以清理的历史媒体；容量恢复后，之前被阻塞的媒体会在系统的下一轮处理周期内自动重试完成下载,不需要手动逐条操作。

## 导出失败或收不到导出通知邮件

- 发起导出前需要**重新输入登录密码完成二次确认**；如果密码验证失败，请确认输入的是当前登录账号的密码（不是企业微信本身的密码）。
- 每月导出次数有限额（文本导出与全量媒体 ZIP 导出分别计算），达到当月上限后需要等到下个自然月重置，或联系客服说明情况。
- 全量媒体 ZIP 导出是异步生成的，完成后会给 Owner 账号绑定的邮箱发送通知邮件。如果长时间收不到通知：
  1. 确认 Owner 账号在系统"设置"中已经配置了有效的通知邮箱；
  2. 检查垃圾邮件/订阅邮件文件夹；
  3. 在"导出记录"页面直接查看任务状态，任务显示"已完成"时即可直接下载，不需要等邮件。
- 下载链接自任务完成起七天后会失效，请及时下载；过期后需要重新发起一次导出。

## 仍未解决怎么办

请联系客服，并尽量提供：出问题的大致时间、你在系统页面上看到的具体状态或提示文字、操作的功能页面名称。请**不要**在工单或聊天中提供密码、企业微信密钥等任何敏感凭据信息，我们不会通过这类渠道索要这些信息。
