# 用户指南

本指南面向刚刚开通「康冠时代企业微信会话存档」的团队管理员（Owner/Admin），介绍产品定位与核心功能，帮助你在几分钟内了解系统能做什么、在哪里操作。

## 产品是做什么的

康冠时代企业微信会话存档是一款面向 1–5 人销售/客服小团队的**企业微信会话存档与合规存证工具**。系统会在企业依法开通并授权的范围内，持续从企业微信官方「会话存档」接口拉取员工与客户之间的沟通记录（文本及常见媒体消息），解密后保存在按租户隔离的数据库和媒体存储中，供 Owner 及被授权的管理员查看、搜索和复核。

产品定位是**留痕与复核**，不是监控工具：

- 只处理企业依法开通、纳入企业微信会话存档授权范围内的沟通，不读取、不监控员工个人微信。
- 系统不会自动判定"飞单"或员工违规，也不承诺 100% 发现所有私下交易；它提供的是可供人工复核的原始记录。
- 归档是**只增不改**的：系统不会向企业微信回写或编辑消息，正常情况下也不会因为容量或其他原因静默删除已归档的记录（参见下文"留存策略"和「故障排查」中的容量说明）。

典型使用场景包括：员工离职或客户交接时回看历史沟通上下文、客诉与交易纠纷时按客户/员工/时间/关键词找到原始聊天、以及日常确认归档同步是否正常运作。

## 权限与角色

系统的管理员账号支持多种角色（在"成员管理"页可见）：`owner`（企业所有者）、`admin`（管理员）、`compliance`（合规）、`legal`（法务）、`readonlyaudit`（只读审计）。不同角色可访问的功能范围不同——例如套餐购买、导出等高敏感操作通常限定给 Owner；具体每个角色的完整权限边界会随产品迭代细化，如有疑问请以系统内实际可见的菜单和操作按钮为准。

登录方式取决于部署的 `AUTH_MODE`：默认使用企业微信 OAuth（员工在企业微信内静默授权登录），也可能配置为临时的用户名/密码登录方式。登录会话有效期为 8 小时。

## 核心功能导览

### 会话审阅控制台

系统提供一个三栏式的会话审阅界面：左侧是员工/联系人选择器，中间是该员工或联系人相关的会话列表，右侧是选中会话的完整消息时间线。这是查看归档聊天记录的主入口。

### 全局搜索

在"消息搜索"页面，可以按发送人、关键词、消息类型、群聊 ID 等条件组合查询归档消息，并从搜索结果跳转回完整的会话上下文。关键词搜索是对消息正文的子串匹配，对中英文混合内容都适用。

### 客户身份线索

系统区分"客户当前昵称"（来自企业微信，客观信息）和"员工备注"（员工对客户的主观备注），两者分开呈现，避免把某个员工的私下备注误当作客户的真实身份;同时会记录客户昵称的历史变更轨迹。

### 同步与容量总览

总览页面展示最近一次同步时间、连接状态、归档结果，帮助 Owner 确认系统是否持续正常工作,而不是等出问题才发现缺记录。页面上也可以查看当前套餐、已用/剩余存储容量。遇到同步看起来卡住时，管理员可以在系统内手动触发一次同步（有短暂冷却时间，避免重复点击造成并发问题）。

### 留存策略

Owner 可以为本企业设置消息留存天数（1–3650 天），并可以选择将该设置"锁定"为不可再修改，用于向团队或客户承诺一个稳定的合规策略。留存策略目前用于标记超出留存期限的历史消息，系统不会因此删除任何已归档的消息内容。

### 导出与审批

已归档的会话记录支持导出，用于对外提交证据或存档备份：

- **文本导出**：按会话、参与人、消息 ID 或时间范围筛选，生成 PDF 或 Excel 文件（单次同步导出上限 5 万条）。
- **全量媒体导出**：生成包含企业全部已下载媒体原始文件的 ZIP 包，异步生成，完成后通过邮件通知，下载链接七天后失效。

两类导出都需要 Owner **重新输入登录密码进行二次确认**，获得一次性审批令牌后才能真正执行导出，用于降低误操作和内部滥用风险。导出额度按自然月重置，当前额度为每月最多 10 次文本导出、1 次全量媒体导出（以系统内导出配额页面的实时数值为准）。

### 成员与权限

"成员管理"页面展示本企业下所有已登录过的管理账号，可按角色、状态、活跃时间等筛选。

### 审计日志

系统记录关键操作（如配置变更、密码修改、导出审批、留存策略变更等）的不可变审计轨迹，可在"审计日志"页面按操作类型、分类、时间等条件筛选查看，作为合规留痕的一部分。

## 数据边界与安全说明

- 访问权限完全由登录身份和所属企业（租户）在服务端解析决定,浏览器无法自报或篡改租户、套餐等信息。
- 每个企业的数据在数据库层面按租户隔离查询,不会跨企业可见。
- 消息在服务端解密（RSA + AES），解密结果只落库为结构化字段，原始解密 JSON 本身不会被完整保存，属于产品在数据最小化方面的设计选择。
