# 企业微信接入前准备事项

> 访问级别：public
> 版本：1.0.0
> 更新时间：2026-08-17
> 资料所有者：Haisu Zuo

本指南适用于云托管版和自托管版的企业微信准备事项。云托管版可通过第三方应用授权自助开通；自托管版由部署者自行配置企业微信应用和受保护的运行凭据。

## 1. 企业微信主体要求

- 你需要拥有一个已完成企业认证的企业微信账号。
- 会话存档接口由企业微信官方提供，必须企业微信侧已开通“会话内容存档”功能权限。

## 2. 接入方式选择

### 方式 A：第三方应用授权（推荐，开通最快）
- 在官网点击“免费试用”，使用企业微信管理员扫码授权。
- 授权后系统会自动完成第三方应用绑定、组织认领与订阅激活。

### 方式 B：自建应用接入
- 适用于对数据存储位置、密钥管理有特殊要求的企业。
- 需要企业微信管理员在“管理后台 > 应用管理”中创建自建应用，并配置接收消息、事件回调等参数。
- 自建应用接入需要自行保管 CorpID、Secret、EncodingAESKey 等凭证，请妥善保存，不要泄露给任何第三方。

## 3. 必须准备的信息

- 企业微信 CorpID
- 企业微信应用/套件凭证（Secret、SuiteID 等，依接入方式而定）
- 可接收回调消息的服务器地址（HTTPS）
- 用于登录与认领的所有者邮箱（官网自助流程）

## 4. 权限与角色

- 只有企业微信管理员才能完成授权或自建应用配置。
- 授权完成后，需在系统内完成“可信所有者认领”，确保租户归属正确。

## 5. 数据与合规提示

- 接入前请确保你已获得员工的知情同意，符合企业内部数据使用规范及适用的法律法规。
- 系统不会主动抓取员工私人微信聊天记录；仅归档企业微信工作会话。
- 不要在非安全渠道（如公开聊天、邮件、截图）中传输 CorpSecret、EncodingAESKey、API Key 等敏感信息。

## 6. 开通后检查

- 授权/配置完成后，系统会进行自动激活检查。
- 激活成功后，会话数据将按企业微信事件回调开始归档。
