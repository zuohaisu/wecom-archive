# 365 企微会话存档 · 产品功能

> 访问级别：public
> 版本：1.0.0
> 更新时间：2026-08-17
> 资料所有者：Haisu Zuo

## 已发布功能

### 1. 企业微信会话存档
- 通过企业微信第三方应用授权或自建应用方式接入，自动归档员工与外部联系人的单聊、群聊文本消息。
- 支持文本、图片、语音、视频、文件、链接、小程序、名片、位置等多种消息类型。
- 提供消息检索、会话时间线、联系人视图与导出能力。

### 2. 安全与权限
- 租户级数据隔离：每个租户拥有独立的加密密钥与存储空间。
- 角色权限：支持管理员、运营人员等角色，按页面与功能粒度控制访问。
- 操作审计：关键操作（登录、导出、配置变更）写入审计日志。

### 3. 自助开通与试用
- 官网自助授权开通 15 天免费试用。
- 试用到期后可续费转为正式订阅。

### 4. 计费与续费
- 提供年费基础套餐，支持在线微信支付续费。
- 订阅状态、续费提醒、宽限期与到期处理由系统根据权威计费规则自动执行。

### 5. 数据导出
- 支持按会话、联系人、时间范围导出文本记录。
- 支持全媒体导出（需相应权限）。

## 功能边界

- 本产品仅归档企业微信侧的员工与外部联系人会话，不获取用户私人微信数据。
- 归档范围以企业微信官方开放的会话存档接口为准。
- 具体可归档的消息类型、存储配额、导出限制以当前订阅套餐为准。
