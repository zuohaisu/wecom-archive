    会话存档回调地址

    在企业微信管理后台“会话内容存档 → API 配置”中填写此地址，并使用与下方相同的 Token 与 EncodingAESKey。

    —

    会话存档 Secret

    —

    企业微信管理后台“会话内容存档”中查看或重新获取。平台无法通过接口代取。

    消息解密私钥（RSA PEM）

    —

    使用 openssl 生成 RSA 密钥对后，将公钥上传至企业微信管理后台，私钥内容粘贴到此处。私钥仅加密保存。

    公钥版本号

    —

    企业微信管理后台上传公钥后显示的版本号，从 1 开始。

    回调 Token

    —

    在企业微信管理后台生成后，将相同的值粘贴到此处。平台不会反向展示该值。

    EncodingAESKey（43 位）

    —

    与回调 Token 一起在企业微信管理后台生成，两个值必须与回调地址配置一致。

    官方操作指引：企业微信会话内容存档接口文档
