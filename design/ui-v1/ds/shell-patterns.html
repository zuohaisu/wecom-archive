信息分层规则

默认可见

租户名、corp_id、状态、创建时间、消息量、存储、活跃坐席、归档天数、同步健康——全部为元数据与聚合指标。

需显式授权

任何会话正文、联系人姓名、附件内容。须发起申请 → 租户管理员审批 → 限时只读凭证（≤2h）→ 双方审计留痕。

永不可见

租户加密私钥明文、已到期凭证下的历史内容、租户管理员密码哈希。UI 层不提供任何入口。

页面骨架约定

.shell
100vh 两栏，页面本身不滚动；滚动发生在 .page 内部，顶栏与侧栏常驻。
.topbar
左侧面包屑（租户 / 分组 / 当前页），右侧动作区：时区说明 → 次要动作 → 主动作。
.page-hd
页面标题 + 一句话说明（说明必须交代数据口径或权限边界），右侧放全页级切换器。
.toolbar
搜索在最左、筛选居中、统计与导出在最右；已生效筛选在下一行以 chip 复述。
.card-ft
表格页脚固定承载分页与总数，永远显示「共 N 条」以支撑取证陈述。
