企业微信会话存档 · UI v1

本目录为设计交付索引。设计语言在既有线上页面（审阅控制台、搜索、诊断）基础上抽取并形式化为一套 CSS 变量，新页面全部基于 styles.css 构建：原生 HTML + 原生 JS，无框架、无构建、无外部图表库，可直接由 SSR 模板消费。
