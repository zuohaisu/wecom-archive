# 康冠时代 Logo 精修与品牌系统 · 交付总览

## 交付了什么

1. **精修 logo（纯矢量，全路径，零字体依赖）** — `logo/svg/` 7 个版本：彩色横版（主标识）、单色黑横版（=注册证形态）、反白横版、彩色竖版、图形标 ×3；`logo/png/` 各版 1x/2x/4x 位图。
2. **favicon 全套** — `favicon/`：favicon.svg（16px 间隙加宽优化）、favicon.ico（16+32+48）、apple-touch-icon（180）、icon-192/512、底板源文件。
3. **品牌系统文档** — `BRAND.md`：康冠蓝色阶（hex+oklch 双标注，对比度全过 WCAG AA）、全 OFL 开源字体体系（思源黑体/Manrope/JetBrains Mono）、净空区/最小尺寸/背景规则/拆分用法/禁用规范、favicon 引用代码、产品与官网应用方案、商标法律备注。
4. **可视化品牌指南** — `brand-guide.html`：上面所有内容的可浏览页面，含产品深色顶栏 before/after、官网导航/页脚摆放示意。
5. **新旧对比图** — `logo/logo-before-after.png`。
6. **可复现工具链** — `tools/`（生成脚本 + 渲染脚本 + 说明）。

## 关键决策

- **合规**：注册证为黑白稿未声明颜色 → 配色自由；文字换成思源黑体（SIL OFL 1.1，可商用可转轮廓）消除原稿字体侵权面；组合关系（图形+康冠时代+CROWN TIME）与注册证完全一致。
- **配色**：主色 #2660B5 → #1F5CC4 同色相提亮；文字 #404040 → #1D2733；增设冠金点缀色（≤5%，仅信任语境）。
- **拆分**：图形标单独用于 favicon/头像/水印；「365」不进 lockup，只作文本副标题。
