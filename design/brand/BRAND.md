## 3. 字体系统（全部开源授权，零侵权风险）

| 角色 | 字体 | 授权 | 说明 |
|---|---|---|---|
| 标志文字 | 思源黑体 Bold（已转轮廓） | SIL OFL 1.1 | 只存在于 SVG 路径中，不依赖字体文件 |
| 中文正文/标题 | 思源黑体 SC（Source Han Sans SC / 思源黑体） | SIL OFL 1.1 | 免费可商用、可嵌入网页 |
| 西文/数字 | Manrope | SIL OFL 1.1 | 几何无衬线，与思源黑体气质匹配 |
| 等宽（消息ID/时间戳/日志） | JetBrains Mono | SIL OFL 1.1 | 存档产品的数据感 |

**不要再用于品牌物料的字体**：PingFang SC（苹果系统字体，许可不允许嵌入商标/网页字体）、微软雅黑（方正授权，商用需付费）、原 logo 来源不明的黑体。

Web 字栈建议（官网与产品）：

```css
--font-brand: "Manrope", "Source Han Sans SC", "思源黑体", system-ui, sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, monospace;
```

思源黑体自托管或国内 CDN（如 fonts.loli.net 的 Noto Sans SC，与思源黑体同源同授权）。

## 4. 标志使用规范

### 4.1 净空区

以图形标中「方块」的边长为 **x**。标志四周净空 ≥ x；任何文字、边框、其他图形不得进入。

```
        ←x→
   ┌───────────────────┐
   │  ▐█▌   康冠时代      │  ↑
   │  ▐█▌   CROWN TIME   │  x
   └───────────────────┘  ↓
```

### 4.2 最小尺寸

| 版本 | 屏幕 | 印刷 |
|---|---|---|
| 横版组合 | 宽 ≥ 120px | 宽 ≥ 30mm |
| 竖版组合 | 宽 ≥ 96px | 宽 ≥ 24mm |
| 图形标 | ≥ 16px（favicon 即 16px 优化版） | ≥ 5mm |

低于最小尺寸时只用图形标，且使用 favicon 优化版（间隙加宽）。

### 4.3 背景规则

- 白/浅色底（Mist 50、White、Blue 50/100）→ 彩色版
- 深色底（Blue 800/900、admin 深色顶栏 #001529、照片深色区）→ **反白版**
- 正式文书/传真/合同 → 单色黑版
- 禁止：彩色版直接放在 Blue 500 或相近明度的蓝底上（标志会消失）

### 4.4 组合与拆分（对应需求「图形和文字允许分开用」）

| 场景 | 用法 |
|---|---|
| 产品深色顶栏、官网导航 | 横版组合（深色顶栏用反白版），高 24–28px |
| 浏览器标签/书签/App 图标/头像 | 图形标单独（favicon、icon-tile） |
| 登录页、启动页、PPT 封面 | 竖版组合居中 |
| 加载动画/水印/文档页眉小标 | 图形标单独，透明度 8–16% |
| 页脚版权行 | 「© 2026 深圳前海康冠时代科技有限公司」是**公司名文本**，不是标志，直接排版即可，无需图形 |
| 「365」副标题 | **不进入标志 lockup**（注册证无 365）。如保留，以文本形式放在标志旁：`康冠时代 · 企业微信会话存档365`，字号 ≤ 标志文字 50%，颜色 Slate |

### 4.5 禁止事项（保护商标显著性，也是「不脱离注册证组合」的操作化）

1. 不拉伸/压扁/旋转/倾斜
2. 不改变图形标三元素的相对位置与比例
3. 不把「康冠时代」换成其他字体重排（资产里已是轮廓路径）
4. 不在标志上加描边/阴影/渐变/发光
5. 不把图形标与文字重排成注册证之外的组合（如文字在图形左侧）
6. 不在低对比或杂乱图片背景上使用（必须使用时垫白色或深蓝纯色块）
7. 不把「企业微信」字样做进标志（腾讯商标，只作描述性文字另排）

## 5. Favicon 与 Web 引用

把 `favicon/` 目录放到站点根（或 `/static/brand/`），`<head>` 加入：

```html
<link rel="icon" href="/favicon/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/favicon/apple-touch-icon.png">
<link rel="mask-icon" href="/logo/svg/logo-icon-mono.svg" color="#1F5CC4">
<link rel="manifest" href="/site.webmanifest">
```

`site.webmanifest`：

```json
{
  "name": "康冠时代 · 企业微信会话存档",
  "short_name": "康冠存档",

  "display": "standalone"
```

## 7. 官网应用方案（static_site/company_homepage）

现状：导航用占位图标（代码括号 SVG）+ 公司全名文本；主色 `#4c56d6`（薰衣草紫，与品牌蓝冲突）。

**方案：**

1. **导航**：占位 `.brand-mark` 替换为彩色图形标或横版 logo（高 28px）；品牌名保留公司全名文本。
2. **Hero**：左侧竖版 logo（宽 140px）+ 标语；或保持现状排版、仅在首屏右上角放图形标水印（透明度 10%）。
3. **主色迁移**：`--color-primary: #4c56d6 → #1F5CC4`，hover `#3c46b8 → #1A4FA9`；四个彩色 icon-tile（蓝/绿/橙/紫）统一为康冠蓝单色系（蓝 500 主、蓝 100 底），官网立刻「像一个公司的产品」。
4. **页脚**：深色区块（Blue 900）+ 反白横版 logo + 公司信息 + 备案号 + 「康冠时代®是深圳前海康冠时代科技有限公司的注册商标」。
5. favicon 全套接入（第 5 节代码）。
6. 如官网涉及本产品，加描述性免责声明：「本产品与企业微信官方无关，『企业微信』为腾讯公司注册商标」。

## 8. 商标法律备注（重要）

1. **续展提醒：注册证有效期至 2026-11-13，现在已在续展窗口期内（期满前 12 个月可办）**。请尽快通过商标局或代理提交续展申请（官费数百元），逾期还有 6 个月宽展期（需额外滞纳金），再逾期商标将被注销。这是本次品牌工作中发现的最紧急事项。
2. 注册为黑白稿 → 蓝色版及任意配色均在保护范围内，但**单色黑横版是注册证的标准形态**，正式法律文件用它。
3. 精修版（思源黑体轮廓）与注册证字形存在合理差异，商业使用无妨；若精修版成为长期使用的主形态，建议**就精修版另行提交一件注册申请**（防御性，费用低），同时保留原注册的使用证据（官网、发票、合同上的使用记录）以防三年不使用撤销风险。
4. ® 标注：在首次出现处用「康冠时代®」即可，不必每次都标；® 只用于已注册的标志本体，不要标在「365」「企业微信会话存档」等未注册名称上。
5. 字体合规：全套品牌字体均为 SIL OFL 1.1（允许商用、嵌入、转轮廓、修改，且 OFL 明确允许用于标志/商标设计）。思源黑体版权归 Adobe/Google，按 OFL 使用无需署名，但不得单独转售字体文件本身。
6. 「企业微信」为腾讯注册商标：产品名中仅作描述性使用（「适用于企业微信的会话存档」语义），官网与 README 需带免责声明，标志本体不含该字样。
