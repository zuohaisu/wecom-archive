## 微信支付 Native AppID 规则事实核查（交付报告）
- 产出：`deliverables/wechat-native-appid-factcheck-2026-08-22.md`（康冠时代会话存档接入微信支付前的独立事实核查）
- **结论 CONDITIONAL**：纯 PC Web 可用 Native（官方为 PC 场景设计），但 **appid 必填且仅限三类**——已认证服务号/公众号、已认证小程序、已认证移动应用；**网站应用 AppID 明确不支持**（开放社区实证：绑定报「当前账户暂不支持该类型appid」；Native FAQ 官方直接答复排除网站应用）。
- 无「免 appid」模式、无商户自动生成/支付专用 appid、无 2025-2026 规则放宽（2025 变更仅限平台证书→微信支付公钥验签模式，与 appid 无关）。
- 企业微信 corpid：绑定清单含「企业微信」，但 Native 准入/FAQ 未列；企微支付是公众号 JSAPI 扩展（企业微信内场景），非 PC Native 路径 → 标记 Unknown/不可用。
- **推荐方案 D**：新建小程序（认证 300 元/年，认证后仅绑定零开发）＞ C 新建服务号（需「有内容」维护）＞ E 移动应用（需包名/BundleID/App 流程图，无真实 App 易驳回）。落地：mp.weixin.qq.com 注册小程序 → 商户平台 AppID账号管理 关联 → 小程序后台确认授权 → Native 下单传该 appid。
- 关键证据 URL 均收录于报告 E1~E12。
