# RND-239 营销网站构建计划

> 方向：取消「迁私有仓库」，改为**在项目内构建前端营销网站**（介绍系统 + 含官网），`company_homepage` 静态页保留并最终被新站取代。
> 本文件锁定**方向决策**（来自 2026-07-26 用户澄清）；**详细架构 / 实现规格见 `rnd-239-execution-prompt.md`，验收见 `rnd-239-qa-prompt.md`**。

## 0. 目标
- 新建前端**营销网站**：介绍「365 企微会话存档」系统（能力、场景、架构、开源信息），并包含官网（品牌展示）。
- 保留在项目内（与开源仓库同源），公开部署。
- **取代**现有 `static_site/company_homepage` 静态页（旧页在实现完成后删除 / 归档，避免重复）。

## 1. 已锁定的决策（2026-07-26 用户澄清）
- **技术栈**：**纯静态 HTML / CSS / JS**（复用并扩展现有 `style.css` 设计语言）。未来如需动态数据再升级，不在本次引入后端 / 框架。=> 不选 Laravel / Livewire / FluxUI（避免后端耦合、保持轻量）。
- **品牌化（RND-234）**：**产品 / 品牌身份为主**——展示「365 企微会话存档」，隐去法律实体敏感字段（ICP 号、公安网安备、真实地址 / 电话 / 邮箱），仅留产品联系入口。=> RND-234 由「泄露应急」重定性为「品牌化决策」，按此落地即收口。
- **与旧站关系**：新站**取代**旧 `static_site/company_homepage`（实现完成后删除旧目录）。
- **首交付**：**先出规划 / 架构提示词**（本仓库约定），不写代码，由用户定执行节奏。

## 2. 技术要点
- 纯静态：无构建步骤或仅可选轻量工具；本地 `python -m http.server` 可预览。
- 设计语言（见执行提示词）：light / dark / system 主题切换、玻璃拟态、磁吸按钮、滚动入场动画（尊重 `prefers-reduced-motion`）、响应式、WCAG 2.1 AA。
- 部署：延续现有 `static_site` 被部署流水线服务的机制；新站落在 `static_site/`（取代 company_homepage）。

## 3. 页面（建议）
- 首页（Hero + 价值主张 + CTA）
- 能力与场景
- 系统架构
- 开源与部署（GitHub / License / ARCHIVE_DOMAIN 说明）
- 联系 / 品牌（产品联系入口，无法律实体敏感字段）
