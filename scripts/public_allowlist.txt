# Public snapshot allowlist — the definitive list of what reaches the
# open-source repository.
#
# ALLOWLIST, NOT A DENYLIST. This is deliberate. A denylist fails open: add
# a new internal directory, forget to exclude it, and it ships. This fails
# closed — anything not named here simply never leaves the private repo.
# The cost is that a genuinely new public path must be added by hand, which
# is the trade we want.
#
# Each line is a git pathspec (file or directory) resolved against tracked
# files only, so untracked local scratch files can never leak in.
# Blank lines and # comments are ignored.
#
# Consumed by scripts/export_public_snapshot.sh (`make public-snapshot`).
