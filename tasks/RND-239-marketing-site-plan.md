# RND-239 营销官网与静态产品 Demo：当前执行计划

> 本文件以 Linear RND-239 的最新票面评论和 Haisu 2026-08-04 批准为准，覆盖本仓库内早期“隐藏主体 / 删除 `company_homepage` / 迁出官网”的过期草案。

## 目标

在项目内维护一套纯静态、可部署的营销官网，介绍 **康冠时代企业微信会话存档**，并通过一套独立、只读、虚构数据的静态 Demo，让客户了解产品内部界面。

## 已批准产品与品牌口径

- 中文产品名：**康冠时代企业微信会话存档**；英文名：**Crowntime WeCom Archive**。
- 官网继续位于并由部署脚本复制自 `static_site/company_homepage/`；不得删除、忽略或迁移该目录。
- 保留：深圳康冠时代科技有限公司、ICP、公安网安备、公开联系邮箱。
- 删除：详细地址、电话号码。
- 保留清晰声明：第三方独立产品，和腾讯及企业微信无隶属、合作或授权关系。
- 套餐：**99 元/年，含 5GB 存储空间，不限座席**；超过 5GB 后，每增加 1GB，增加 **1 元/GB/月**。
- 企业微信会话存档接口的开通及相关官方费用另计。
- 对外仅表述“按存储空间计费”；不得称为七牛官方分销、合作或授权服务，除非另有书面授权。

## 页面结构

### 官网 `/`

1. Hero：不限座席、按存储空间计费；主 CTA 为“查看 Demo”。
2. 价值主张与产品能力：会话归档、检索、审阅、多租户隔离、安全解密、审计留痕。
3. 计费方式：99 元/年含 5GB、超额容量规则、企业微信官方接口费用另计、按座席与按空间的中性对比。
4. 安全与场景：保留现有基础内容，避免不实合规承诺。
5. FAQ：座席、官方费用、空间占用、超额容量、多租户、访问审计、自部署与服务套餐。
6. 底部 CTA：查看 Demo + 真实 `mailto` 咨询入口；页脚保留法律主体与备案信息。

### 静态 Demo `/demo/`

| 页面 | 目的 |
|---|---|
| `index.html` | Demo 总览、容量、产品导航 |
| `conversations.html` | 三栏会话审阅 |
| `search.html` | 关键词与组合筛选 |
| `contacts.html` | 外部联系人与关联会话 |
| `media.html` | 媒体和附件目录 |
| `analytics.html` | 归档量、空间与容量说明 |
| `audit-log.html` | 查看、检索、导出等审计字段 |

Demo 只展示已存在或票面已确认的产品能力；不展示尚未落地的历史昵称追踪、平台超管、自动开通等能力。

## 技术与安全边界

- 仅 HTML、CSS、原生 JavaScript；无框架、构建链、CDN 或后端调用。
- Demo 采用合成企业、人员、会话、附件、ID 和统计数字，并在每页显著标识为静态演示环境。
- Demo 不登录、不请求 API、不追踪、不导出、不下载、不写入。
- 可复用仓库设计参考的视觉语言，但不直接发布 `design/ui-v1/` 中的设计稿；其中有尚未实现的占位页面。
- 不改动后端、部署脚本、DNS/CDN、认证、Worker、数据库或其他 worktree 的文件。
- 不 commit、push、创建 PR 或部署生产。

## 验收重点

- 官网与 Demo 能经 `python3 -m http.server` 独立预览。
- 所有“预约演示”改为“查看 Demo”，并指向实际 `/demo/` 静态入口。
- 价格、容量和官方接口费用口径准确；未创建支付或自动开通流程。
- 详细地址和电话号码无公开展示；公司主体、备案、邮箱和免责声明保留。
- Demo 不含真实数据、凭证或网络请求；所有内部链接和资产可用。
