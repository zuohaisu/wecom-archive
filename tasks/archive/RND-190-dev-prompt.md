# RND-190 — 服务器资源基线与瓶颈报告 执行提示词（运维版）

> 给运维同学的测量 SOP。PM 不修改任何代码/配置，本文件仅描述"测什么、怎么测、产出什么"。

## 1. 背景与目标
- 父任务：RND-160（2 核 2GB 阿里云 ECS 服务器资源优化）。
- 本任务目标：在动手优化前，先建立**可复现的资源基线**，定位主要瓶颈，给后续 RND-191（API/SQL）、RND-192（Worker/媒体）、RND-193（日志/磁盘）提供明确输入。
- 原则（来自 RND-160）：**先测量，再优化；每个子任务独立验收；不在本任务做大范围代码或生产配置修改。**

## 2. 范围（要测的）
- 系统层：CPU、内存、swap、load、磁盘空间与 inode、网络。
- 进程层：FastAPI/Uvicorn、PostgreSQL、Nginx、systemd timer / worker 的资源占用。
- 关键 API（用真实或近似生产数据打）：员工列表、会话列表、消息时间线、搜索、媒体访问。采集：响应时间、响应体大小、查询行数、慢查询。
- 后台任务峰值：归档同步、解密、图片下载运行时的峰值资源。
- 增长趋势：日志、数据库、媒体文件的体积增长速度（按天/按周采样）。

## 3. 非目标（不要做）
- 不实施大范围性能优化。
- 不升级服务器配置。
- 不修改业务语义或数据结构（除非为只读诊断临时加观测，且不影响主流程）。

## 4. 测量方法（命令与场景）
> 以下为常见工具，按实际环境选用；所有采集均为只读，不要改配置。

### 4.1 系统基线（建议连续采样 1–3 天，含业务高峰）
- CPU/负载：`uptime`、`top -b -n1`、`vmstat 1 5`、`sar -u 1 5`（无 sar 则略）
- 内存/swap：`free -h`、`cat /proc/meminfo`
- 磁盘空间/inode：`df -h`、`df -i`
- 磁盘 I/O：`iostat -x 1 5`（无则 `iotop` 或 `vmstat` 的 io 列）
- 网络：`ss -s`、`sar -n DEV 1 5`、`ip -s link`

### 4.2 进程占用
- `ps aux --sort=-%mem | head`、`ps aux --sort=-%cpu | head`
- 若容器化：`docker stats`（或对应 runtime）
- 针对 PostgreSQL：`pg_top` / `htop` 过滤 postgres 进程

### 4.3 关键 API（用代表性账号/数据）
- 用 `curl -w "@curl-format.txt"` 或 `ab` / `hey` 打：员工列表、会话列表、时间线（长会话）、搜索、媒体访问。
- 记录：P50/P95/P99 响应时间、响应体大小（HTTP `Content-Length`）、是否触发慢查询。
- PostgreSQL 慢查询：`SELECT query, mean_exec_time, calls FROM pg_stat_statements ORDER BY mean_exec_time DESC LIMIT 20;`（需 `pg_stat_statements` 已启用；若未启用，临时开启属只读诊断，但应先确认不影响主流程，必要时沟通后再做）。

### 4.4 后台任务峰值
- 在归档同步 / 解密 / 图片下载运行窗口，用 4.1/4.2 的命令高频采样（每 10–30s 一次，持续数分钟）。
- 记录峰值 CPU%、内存、磁盘写入速率。

### 4.5 增长趋势
- 日志：`du -sh /var/log/<app>/*` 连续多日对比。
- 数据库：`SELECT pg_database_size('dbname');` 每日记录。
- 媒体：`du -sh <media_dir>` 每日记录。
- 给出日均增长量估算。

## 5. 交付物（基线报告，建议 Markdown）
1. **采集命令与测试场景清单**（可复现）。
2. **当前资源基线表**：CPU 均值/峰值、内存均值/峰值、swap、load、磁盘使用率、inode、网络。
3. **进程占用表**：各组件（app / db / nginx / worker）的 CPU/内存。
4. **关键 API 性能表**：端点、P50/P95/P99、响应体大小、慢查询标记。
5. **后台任务峰值记录**。
6. **增长趋势**：日志 / DB / 媒体日均增长。
7. **瓶颈清单（至少前 5 项）**，按"影响 × 成本"排序，并区分：代码 / SQL / 配置 / 任务调度 / 容量。
8. **后续优化建议排序**：明确指向 RND-191 / RND-192 / RND-193。
